这次更新修复长截图的窗口误判，并把常用标注和翻译结果放回截图操作中。

### 长截图

- 修复正常窗口被误报为「已关闭或最小化」、无法开始或继续长截图的问题。
- 按实际在屏窗口确认目标，保留窗口身份、移动与尺寸检查；无法读取状态时提供准确的重试提示。

### 截图工具栏

- 缩小按钮与间距，矩形、椭圆、箭头、画笔、文字和马赛克直接可点。
- 颜色、线宽、撤销和重做放在手边，其余标注工具可从「更多」展开。
- OCR 与翻译分别提供入口，长截图保持可见文字，右侧对号完成并自动复制。

### 截图内识别与翻译

- 原文与译文直接显示在截图工具栏下方，截图和标注会话保持打开。
- 支持编辑原文、选择翻译服务与目标语言、复制原文或译文；识别和翻译错误在卡片内重试。
- 改变选区、修改标注或关闭截图时取消旧请求，防止过期结果覆盖当前截图。
- 需要处理全文时可主动展开完整工作区，沿用已识别文字和翻译状态。
- 关闭文字卡片后恢复截图的键盘操作，Enter 仍可完成并复制。
- 修正 Google 翻译申请顺序：先在同一项目启用 Cloud Translation API，再创建并限制 API Key。
