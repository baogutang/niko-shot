框选恢复跟手，快捷键可以删除，界面改成标准的 macOS 样式。

**框选**
- 拖动选区重新跟手。0.5.2 每移动一下鼠标就会重新排版一次工具栏，并且要等下一次屏幕刷新才画出选区，所以在部分 Mac 上明显卡顿。现在拖动时工具栏先隐藏，松手后再出现，选区随鼠标同步绘制。
- 第一次点击就能开始框选，不必先点一下激活窗口。
- 截图、关闭窗口或取消之后，键盘焦点回到原来的应用，⌘V 可以直接粘贴。选择「保存」时，焦点会等保存面板关闭后再回去。
- 倒计时不再抢走焦点，其他应用里打开的菜单可以保持展开。

**快捷键**
- 每个全局快捷键都可以删除：在「设置 → 快捷键」里选中后按 Delete，或者点 ✕。与其他应用冲突时，删掉或换一个即可。
- 新安装只设置 ⇧⌘A 区域截图，其他功能都在菜单栏里。从旧版本升级的用户会保留原有的快捷键。

**界面**
- 设置改成标准的 macOS 设置窗口，分为通用、截图、快捷键、文字识别、翻译和录屏六个标签。
- 菜单栏图标改用系统原生菜单，显示快捷键和最近截图，按住 ⌥ 可以把截图贴到屏幕。
- 窗口使用系统配色，唯一的品牌色是图标上的琥珀色。文案也改得更短。
- 像素尺寸不再按地区格式显示，例如不会再把 2560 显示成「2.560」。
- GIF 导出的宽度滑块不再显示成一条黑色刻度。

**长截图**
- 修复：窗口底部有固定输入栏时，正文会被误当成浮层抹掉。
- 修复：抹除浮层时会连带抹掉旁边的文字。
- 只在浮层真正出现过的画面里抹除它，滚动更稳定，截取画面也不再阻塞界面。
- 控制条加宽，提示文字不再显示一半。
- 自动滚动连续对不上时会停下并提示，不再直接结束。
- 切换显示器时保留已拼好的内容和选区。

**录屏**
- 在菜单栏停止录制或拔掉显示器时，不再删除已经录好的视频。
- 修复超过 4K 的屏幕用 H.264 录制会失败的问题，画面会自动缩小到编码器支持的尺寸。
- 修复多声道麦克风无法录音的问题。
- GIF 中的灰色不再偏色。
- 录制超过 5 秒后按 Esc，会先询问是否放弃。
- 快捷指令或命令行录屏没有指定输出路径时，直接保存到桌面。
- 保存时直接移动文件，不再额外复制一份；超过 7 天的临时录屏会自动清理。

**截图与输出**
- 新增自动保存：在「设置 → 截图」中打开后，每张截图复制到剪贴板的同时，会按设定的格式和文件名存进指定文件夹（默认桌面），不会覆盖同名文件。
- 从缩略图拖出的文件可以放进终端、网页上传框等只接受文件的地方，文件名包含截图时间。
- 导出的图片带有像素密度信息，Retina 截图在预览和 Keynote 中按实际大小显示，贴图也不再放大一倍。
- 小选区不再占用整块屏幕的内存。
- 历史搜索支持前缀和多个关键词，例如「Eng」可以匹配「English」。
- 另存为时切换格式，不再覆盖已经输入的文件名。

**安全**
- `niko-shot://` 链接只能打开需要你亲手操作的界面，不能静默截全屏，也不能写入任意路径。
- 命令行静默截图（全屏、按窗口 ID、读取最近识别的文字）默认关闭，需要在「设置 → 通用」中打开。
- 复制的 API 密钥只留在本机，不同步到其他设备，60 秒后从剪贴板清除。

Apple 芯片和 Intel 各有独立的 DMG、ZIP、SHA256 校验和构建信息。仍使用同一张 NIKO 证书签名，升级后不需要重新授权。
