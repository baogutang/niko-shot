修复外接屏菜单裁切与未配置翻译服务时的自动跳转，重新整理日常操作界面。

- 菜单按点击所在屏幕的可见范围定位，顶部为菜单栏与弹窗箭头预留空间；窗口边缘会自动避让。屏幕布局变化时关闭原菜单，避免遗留在已经移除的显示器位置。
- 最近截图缩略图按显示尺寸适配，不再受原图尺寸影响而裁切；最近截图区使用固定高度，内容增多时在菜单内部滚动；顶部截图入口与底部设置、退出始终可见。
- 当前翻译服务未配置或凭据不完整时，文字识别保留原文，可继续编辑与复制，不自动发送请求，也不显示缺少密钥的错误。配置好的服务继续按自动翻译偏好工作，不切换到其它服务。
- 配置检查只读取钥匙串条目属性，避免在打开菜单或文字结果时要求解密密钥。
- 保存、移除密钥或切换服务后，已打开的文字结果同步刷新；移除配置会取消待发请求并回到原文。无需 API Key 的自定义 REST 服务继续可用。
- 工具栏按标注、文字与长截图、输出分组，两排从左侧对齐；撤销与重做保持可见，右侧固定「✓ 完成」并复制截图。
- 菜单减少重复装饰；设置、历史、录屏与文字工作区统一系统自适应底色、SF Symbols 和字体。未配置翻译时，完整文字工作区也只展示原文。

Apple Silicon 与 Intel 分别提供独立 DMG 和 ZIP 安装包。
