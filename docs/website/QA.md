## 边界

减少动态效果与透明度的 CSS / 清理路径已复核；当前机器锁屏，不能代替用户更改系统偏好进行真实体验验收。颜色对比已按最终 token 校验，性能报告需在发布后独立检查。浏览器截图与静态验证不替代 Lighthouse 分数、屏幕阅读器完整走查或产品实机验收。

应用离屏预览不能替代新版本活动窗口的拖拽、快捷键和 VoiceOver 走查。Developer ID、公证、真实翻译账号、双 DPI / 120 Hz、外设及现有未达标性能预算保持在 [完整验收记录](../ACCEPTANCE.md)，所有功能需求继续保留。
