安装前，你可能想知道。

需要哪些系统权限？

截图和录屏需要屏幕录制权限。麦克风、摄像头在启用对应录屏功能时使用；自动滚动按需使用辅助功能权限。应用内提供申请与检查入口。

翻译服务需要单独申请吗？

需要。应用直接连接你的 API 服务，不附带共享密钥。各服务的申请、计费和凭据类型不同，请查看 最新接入指南。未启用认证的自托管 LibreTranslate 可免密配置。

为什么下载的是开发候选？

源码已通过本机干净构建和 169 项测试，GitHub 会先测试再打包。但真实账号、外设和部分性能预算尚未完成验收，当前产物也未 Developer ID 公证。请结合 验收记录试用。

如何反馈问题或自行构建？

在 GitHub Issues 提交系统版本、复现步骤与经过脱敏的示例。构建只需 Xcode 和 XcodeGen，详见 README。
