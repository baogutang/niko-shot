开通百度通用翻译

在百度翻译开放平台开通通用文本翻译 API，取得同一开发者账户的 APP ID 与密钥。

所需凭据 · APP ID / 密钥

1. 申请服务

登录百度翻译开放平台注册开发者，完善平台要求的资料。选择通用文本翻译 API 及服务版本，完成该版本需要的认证与开通。

服务开通 · 通用文本翻译 API

2. 填入凭据

从同一开发者账户取得 APP ID 与密钥，确认通用文本翻译服务已生效；在本应用百度服务设置中分别填入这两项。

开发者控制台 · 百度翻译开放平台

3. 测试连接

保存后点击测试连接，实际请求 Hello, world! → 简体中文。成功时显示译文，失败时在当前服务显示原始错误码或 HTTP 状态。

参考文档 · 百度通用文本翻译 API

本应用接入通用文本翻译 API；申请时请确认服务类型与上述产品一致。

认证条件、计费和额度以所选服务版本及账户内的最新信息为准。

如果设置了 IP 限制，需要允许这台 Mac 发送请求时使用的公网出口 IP。

开通 Google Cloud Translation

本应用使用 Cloud Translation Basic v2，通过项目的 API Key 请求文本翻译。

所需凭据 · API Key

1. 申请服务

登录 Google Cloud，创建或选择有管理权限的项目，关联可用的结算账户，并在同一项目启用 Cloud Translation API。官方要求启用计费。

开通指南 · 项目、计费与 API

2. 填入凭据

在该项目创建 API Key，将 API 限制设为 Cloud Translation API，应用限制需允许本机 REST 请求。将完整 API Key 填入本应用 Google 服务设置。

凭据控制台 · Google Cloud

3. 测试连接

保存后点击测试连接，实际请求 Hello, world! → 简体中文。成功时显示译文，失败时在当前服务显示原始错误码或 HTTP 状态。

参考文档 · Basic v2 translate

Basic v2 支持 API Key；Advanced v3 不支持这种认证方式。本应用此处只需要 API Key。

密钥所属项目必须同时启用 Translation API 与计费；费用和使用额度以 Google Cloud 账户为准。

网站 Referer、Android 和 iOS 的应用限制不适用于本应用的 macOS REST 请求。使用 IP 限制时填写公网出口 IP，网络变化后需重新核对。

参考文档 · 有道文本翻译 API

应用 ID 与应用密钥来自智云 API 应用；有道词典会员或账户登录密码不能用于这些输入框。

开通 DeepL API

选择面向开发者的 DeepL API 套餐并取得 API Auth Key；已有 API Free / Pro 账户可继续使用其有效密钥。

所需凭据 · Auth Key

1. 申请服务

阅读当前 API 套餐说明，选择 Developer API、Growth API 或 Enterprise API，按官方申请流程完成 API 账户开通。已有 API Free / Pro 账户可使用有效密钥。

申请与套餐说明 · DeepL API

2. 填入凭据

在具备 API 权限的账户中创建或复制用于翻译的 API Auth Key，在本应用 DeepL 服务设置中粘贴完整密钥，保留原有后缀。

密钥管理 · DeepL API 账户

3. 测试连接

保存后点击测试连接，实际请求 Hello, world! → 简体中文。成功时显示译文，失败时在当前服务显示原始错误码或 HTTP 状态。

参考文档 · API 端点与认证

截至核对日期，官方说明 API Free 与 API Pro 不再接受新购买；新申请请查看当前 Developer / Growth / Enterprise API 套餐。

DeepL 网页或桌面翻译订阅与 DeepL API 套餐是不同产品。需要取得具备 API 权限的密钥。

应用按官方认证规则自动选择端点：以 :fx 结尾的完整密钥使用 api-free.deepl.com，其余使用 api.deepl.com；请勿自行添加或删除后缀。

当前文档和官方 SDK 保留上述端点规则；新套餐实际发放的密钥后缀与真实账户连通性尚未在本应用中验证。

配置自定义 REST 翻译

按所选服务申请自己的 API Key / Token，或连接允许免密访问的自托管实例。彩云、官方托管和自托管是不同接入路径，任选适用的一种。

所需凭据 · API Key / Token（需要认证时）

1. 申请服务

按所选服务任选一条路径：彩云在开发者平台注册并申请小译 API Token；LibreTranslate 官方托管在密钥门户购买 API Key；自托管连接自己的实例，有认证时向管理员领取密钥，无认证时可免密。各路径官方入口列在下方。

申请与参考文档 · 彩云小译 API

2. 填入凭据

新建自定义服务并选择预设，填写名称、URL、Headers、Body 与响应路径，需要认证时填入该实例的 API Key / Token。LibreTranslate 免密实例需删除 api_key 字段及模板中全部 $KEY 占位符，密钥可留空。

开发者控制台 · 彩云小译 API

3. 测试连接

保存后点击测试连接，实际请求 Hello, world! → 简体中文。成功时显示译文，失败时显示原始错误码或 HTTP 状态；检查服务地址、认证、语言和响应路径。

参考文档 · LibreTranslate API

彩云小译 App / 网页会员账户与小译 API Token 分属不同产品；请使用开发者平台发放的 API Token。

LibreTranslate 官方托管密钥来自其官方门户；自托管实例的密钥由实例管理员管理，两者不能互换。

LibreTranslate 自托管默认可不启用 API Key 验证。预设包含 api_key 和 $KEY；免密实例需删除这些认证内容，无需为本应用强行启用密钥验证。

只有 URL、Headers 或 Body 模板包含 $KEY 时，本应用才要求该实例的密钥。密钥单独保存在系统钥匙串，不要直接写入模板。

计费、可用语种和额度由所选服务或自托管实例决定。官方导航使用 HTTPS；本地自托管服务地址按你的部署填写。
